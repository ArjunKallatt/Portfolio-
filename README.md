# Arjun Kallatt — Portfolio

A personal portfolio site built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## Highlights

- Kinetic split-character hero type animation
- Custom cursor with magnetic hover states
- Pinned horizontal-scroll project showcase
- Scroll-linked parallax and reveal choreography throughout
- Warm ink/gold editorial palette, Fraunces + Manrope type system

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```
